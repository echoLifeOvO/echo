# 作品、发布与回应

这里逐步保存视频及其他作品。没有作品时不预建流水线。作品可关联多个学习主题，学习也不必转成作品。

每个作品用独立目录和入口文档记录意图、相关学习、当前状态及文件位置。随进展添加脚本、分镜、制作记录和反馈；简单作品不必拆很多文件。

可选状态：构想、制作中、可审阅、已发布、暂停。只有实际发布并取得链接后才能写“已发布”。准备发布与实际发布分开，后者需要用户授权。

发布记录包含平台、日期、链接和版本。反馈写明观测时间、真实数据或内容、用户如何理解它，以及是否引出后续作品；没有数据就留空。私信不直接进入公开资料，引用前取得相应授权或充分匿名化。

视频、音频和大体积生成媒体默认不进入 Git；保存脚本、提示词、工具/参数、素材出处、授权信息、文件位置和可复现步骤。不要把所有作品都限定为教学讲解：实验、表达、工具迭代和个人变化也可以成为作品。
