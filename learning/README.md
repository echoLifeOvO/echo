# 学习主题索引

方向随实际探索增加。目前尚未新建知识主题；项目动机记录在 [愿景](../docs/vision.md)，此前的探索见 [已有资料地图](../docs/existing-materials.md)。提到过尼采等内容不代表已经学过，不提前建立空的学习成果。

## 组织方式

使用 `<方向>/<主题>/README.md` 作为主题入口，例如未来确实学习某概念时再创建相应路径。主题变长后再拆成理解笔记、来源、实验、未解问题等子文档；目录名简短稳定，标题可以用中文。

一篇主题文档可以按需写下：

- 起点：为什么感兴趣，最初想问什么。
- 当前理解：关键概念、推理、例子，哪些已验证、哪些只是猜想。
- 我的想法：用户自己的判断、联系或认识变化；AI 建议单独注明。
- 依据：资料标题、作者、链接、访问日期，必要的章节或页码。
- 留下的问题：卡住之处、分歧和可能继续的方向。
- 相关产物：实验、代码、研究报告、视频与反馈的相对链接。
- 更新记录：有意义的日期与认识修正。

这些是提示，不是每篇必填的表格。一个重要疑问也值得保存。优先维护已有笔记，跨方向建立链接。新增主题后在本页增加“方向 / 主题 / 当前状态 / 路径”，方向较多时再建立各自的索引。
