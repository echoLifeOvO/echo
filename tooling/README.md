# 工具与工作流

随真实需要积累帮助学习、创作、发布和整理的工具，包括脚本、skill、插件、Agent 与工作台。当前不预设技术架构。

每个工具或流程记录：遇到的具体问题、使用方法、输入输出、依赖与配置、验证结果、限制和相关探索。可复用代码与配置模板进入 Git；令牌、个人配置和依赖不进入。

已有 `.codex/skills/` 保存了一组小说改编游戏相关技能，本次未修改，参见 [旧资料地图](../docs/existing-materials.md)。今后可以按需整理纳入版本管理，不复制出两个不一致的版本。

- [知识板](dsh-knowledge-board/README.md)：DSH 客户端插件，在对话区顶部加一个页签，用无限画布展示本地文件驱动的学习内容；对话学习时的主要信息载体。
- [会话花费](dsh-session-cost/README.md)：DSH 客户端插件，在输入框下方显示本会话花费与账户余额；花费按会话日志本地计算，余额低频缓存读取。
- [会话地图](dsh-session-map/README.md)：DSH 客户端插件，把工作区和会话铺成一整窗画布，卡片实时显示在跑/待确认/未读；启动自动收起侧栏。
