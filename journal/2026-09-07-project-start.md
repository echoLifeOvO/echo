# 建立长期学习项目

用户确认将当前文件夹作为个人终身学习项目，用根 `AGENTS.md` 说明目的与协作方式，以不同方向和子文档持续沉淀，并用 Git 管理。学习、视频、发布相关工具与流程将在同一项目内逐步积累。

本次明确：好奇与乐趣是驱动，知识、作品、人与人之间的反馈和个人变化均属于学习。学习不以职业用途为必要前提，也不排斥收入与声誉。

已建立项目约定、愿景、学习/调研/作品/工具/日志入口和旧资料地图。现有资料保留原位，两个嵌套 Git 仓库保持独立，初次提交仅包含新增基础文档与忽略规则。

尚未决定账号名称、具体平台或第一期内容。后续从真实兴趣继续，无需为填充目录而选题。

完整背景见 [愿景](../docs/vision.md)。
