# 个人终身学习项目

借助 AI，学点好奇的，做点喜欢的。通过实际投入，慢慢发现自己愿意过怎样的生活。

这里积累问题、理解、实验、作品、工具和人与人之间的回应。学习、创造和公开交流都是实践本身的一部分。项目名与社交账号名尚未确定。

## 导航

- [协作与沉淀约定](AGENTS.md)：进入本项目的 Agent 先读这里。
- [愿景与当前构想](docs/vision.md)：为什么做，以及已确认和未确定的事情。
- [学习主题索引](learning/README.md)：各方向长期积累的入口。
- [专项调研](research/README.md)：资料、来源与证据。
- [作品与公开反馈](creations/README.md)：学习到视频、发布与后续回应。
- [工具与工作流](tooling/README.md)：逐步沉淀 skill、插件、Agent 和制作方法。
- [实践日志](journal/README.md)：个人变化与项目决策。
- [已有资料地图](docs/existing-materials.md)：当前文件夹原有内容的位置与管理状态。

## 使用方式

直接在这里提出感兴趣的问题。一个主题探索到阶段节点后，更新相应文档并留下来源、未解问题和作品链接；下次从已有理解继续。方向与目录按需要增加，允许一篇文档开始，也允许没有成品的探索。

根目录使用本地 Git 管理。本次建立的项目文档构成初始版本；原有项目和资料保留原位，逐步整理。忽略项没有被删除，也没有被根仓库备份。暂未配置远程仓库。
